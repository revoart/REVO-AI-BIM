**Project:** Revo AI BIM
**Phase:** 2 — Revit plugin interface

## 1. Delivered

### Ribbon

Tab **REVO AI BIM** with four panels:

| Panel | Controls |
| --- | --- |
| Revo AI BIM | Workspace |
| Scan | Import Scan, Scan Analysis |
| BIM | Generate BIM, Model Review, Quality Check |
| Project | Settings, About |

Every button has 16 px and 32 px icons generated by
`scripts/generate-icons.ps1` and embedded as WPF resources. Commands for
Phases 5-8 show explicit "not implemented" dialogs; they never create
placeholder geometry. Import Scan and Scan Analysis were dialogs in the Phase 2
build and became real point cloud import (Phase 3) and geometric analysis
(Phase 4).

### Workspace (modeless WPF)

- Project information: project name, document path, Revit version/build,
  project units, level count.
- Point cloud panel: scan file, point count, status (honest empty state).
- Reconstruction settings: building type, wall height, floor thickness,
  confidence threshold, "mark inferred geometry".
- Levels: list of document levels, add new level rows, remove pending rows,
  **Create levels in Revit** (real transaction).
- Processing: progress, status, detected elements (0), mean confidence (—),
  error list.
- Engine: live **Test connection** that starts the Python process, performs the
  handshake and ping, and reports version/capabilities; log-folder shortcut.

### Settings and About

- Settings edits interpreter, engine root, startup/request timeouts; validates
  paths and numbers; writes `%APPDATA%\RevoAI\config.json`.
- About shows product version, Revit version, protocol, log folder, and states
  clearly that this is a Phase 2 preview.

### Threading and transactions

- `RevitTaskRunner` queues work and raises `ExternalEvent`; the WPF thread never
  touches Revit objects.
- `DocumentReader` is the only Revit read/write surface for the workspace.
- Level creation runs in one `Transaction`, skips existing names, rolls back on
  failure and logs the result.

## 4. Manual verification steps

1. Build and install Release for 2026:
   `scripts\build.ps1 -RevitVersion 2026 -Configuration Release`
   `scripts\install-addin.ps1 -RevitVersion 2026 -Configuration Release`
2. Launch Revit. Expect the **REVO AI BIM** tab.
3. Open **Workspace**. Confirm project fields and levels load.
4. Click **Test connection**. Expect `Connected`, engine 0.2.0, Python 3.14.7,
   capabilities `initialize, ping, shutdown`.
5. Add a level row and click **Create levels in Revit**. Confirm it appears in
   the Revit level list; click again and confirm it is skipped, not duplicated.
6. Open **Settings**, change a timeout, Save, reopen and confirm persistence.
7. Open **About**; confirm version and Revit build.
8. Click Scan Analysis / Generate BIM / Model Review / Quality Check; confirm
   honest dialogs and no model changes. Import Scan is covered by the Phase 3
   verification instead.
9. Repeat on Revit 2027.
